# ShopSphere — E-Commerce Product Catalog

ShopSphere is a responsive e-commerce web application built with React and Vite. It allows users to browse products, search and filter the catalog, sort products by price, and manage a shopping cart.

## Features

- **Product Catalog:** Browse products with images, prices, and categories.
- **Search:** Find products by name.
- **Category Filtering:** Filter products by category.
- **Price Sorting:** Sort products by price.
- **Shopping Cart:** Add and remove products and update quantities.
- **Cart Persistence:** Cart items are saved in localStorage.
- **Client-Side Navigation:** Navigate between Home, Products, and Cart.
- **Responsive UI:** Clean layout for a modern shopping experience.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router
- Browser localStorage

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/chalanapadpu/shopsphere.git
   ```

2. Open the project folder:

   ```bash
   cd shopsphere
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```

## Deployment

The application is intended to be deployed using Vercel.
